PAW NAILO RUST - COMO USAR

METODO 1: JOGADOR (RECOMENDADO)
1. Baixe o arquivo PAW-Nailo-vX.X.X.zip na aba Releases do GitHub.
2. Clique com o botao direito e selecione "Extrair Tudo".
3. Abra: Abrir PAW Nailo.bat (ou paw-nailo-rust.exe diretamente).
4. O launcher abre instantaneamente em menos de 1 segundo!
   (Nao precisa instalar Rust, Visual Studio nem ferramentas de programacao).

METODO 2: DESENVOLVEDOR (COMPILACAO DO CODIGO-FONTE)
1. Clone o repositorio do GitHub.
2. Certifique-se de ter instalado:
   - Rust (https://rustup.rs/)
   - Microsoft C++ Build Tools (MSVC com a carga C++ Desktop)
3. Execute "Abrir PAW Nailo.bat" para compilar e iniciar.
4. Para gerar o pacote ZIP de distribuicao, execute "empacotar-release.bat".

ATALHOS:
Crie um atalho na Area de Trabalho apontando para "Abrir PAW Nailo.bat"
ou diretamente para "paw-nailo-rust.exe".

SEGURANCA:
Dados e credenciais ficam criptografados em %APPDATA%/pawnailo via DPAPI.
Nao requer Node.js nem Python.
